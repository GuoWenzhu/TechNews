# TechNews · 科技情报日报

TechNews 收集、筛选和整理科技新闻，并以 Markdown 日报形式发布到 [GitHub](https://github.com/GuoWenzhu/TechNews)。项目重点关注人工智能、AI Agent、软件工程与技术落地，帮助读者追踪行业动态、理解技术趋势，并发现与现有项目相关的研究和实践机会。

## 关注领域

- **人工智能**：大模型、模型能力、训练方法与研究进展。
- **AI Agent**：智能体框架、工具链、编程助手与应用实践。
- **软件工程**：开发工作流、代码审查、基础设施、安全与部署。
- **技术落地**：产品发布、行业应用、数据分析与工程经验。

## 信息来源与筛选

信息来源的唯一权威清单是 [`config/sources.json`](config/sources.json)（结构化 JSON，加源 = 编辑该文件）；根部 [科技情报来源清单.md](科技情报来源清单.md) 为其自动生成的只读展示版，禁止手工编辑。来源分三个层级：

| 层级 | 来源类型 | 主要用途 |
| --- | --- | --- |
| T1 | 公司一手工程与研究博客 | 获取原始发布、技术细节与实践经验 |
| T2 | 科技媒体与热点聚合平台 | 观察行业热度与讨论焦点 |
| T3 | 论文与模型发布平台 | 跟踪值得关注的前沿研究与模型进展 |

日报主要关注近 48 小时的新内容，按一手性、信息密度以及与工程、Agent 和 AI 落地的相关性筛选，通常保留不超过 10 条重点资讯；有价值的内容不足时，按实际数量收录。采集、去重与来源维护的执行规则见 [`rules/collection.md`](rules/collection.md)。

## 项目结构

```text
TechNews/
├── README.md                  # 项目说明
├── config/
│   ├── project.json           # 项目级配置（采集窗口、筛选数量、权威文件指针）
│   └── sources.json           # 唯一权威来源清单
├── rules/collection.md        # 采集与维护执行规则
├── docs/data-contract.md      # 数据契约（目录、schema、台账约定）
├── scripts/validate.py        # 配置与数据契约校验、展示版生成
├── state/                     # 持久运行台账（去重、健康、发布记录、维护日志）
├── reports/                   # 简报归档 digest-YYYY-MM-DD.md
├── data/                      # 原始抓取临时文件（本地，不入 Git）
├── backup/                    # 配置修改前的字节备份（本地，不入 Git）
├── old/                       # 2026-10-10 前历史简报（本地，不入 Git）
└── 科技情报来源清单.md          # 只读展示版（由 config/sources.json 生成）
```

修改 `config/sources.json` 后运行 `python3 scripts/validate.py --generate-md` 重新生成展示版；提交或发布前运行 `python3 scripts/validate.py` 全量校验。

## 日报内容

每期日报为纯新闻简报：日期、今日摘要、新闻条目（标题、发布时间、来源、核心内容、必要背景/影响、原始链接）。无重要新闻时只写"今日暂无值得收录的重要科技新闻"。来源健康与维护记录在 `state/`，不进入简报。

## GitHub 发布与归档

日报按日期保存为 `reports/digest-YYYY-MM-DD.md`，在 GitHub 仓库中持续发布和归档。读者可直接浏览文件、查阅原始来源，并通过提交历史查看内容变化。

## 阅读方式

- 浏览 `reports/` 中的日报文件，按日期了解科技动态。
- 从「今日要点」快速掌握重点，通过原始链接深入阅读。
- 对照历史日报，观察同一主题的演进与持续信号。
