# TechNews · 科技情报日报

TechNews 收集、筛选和整理科技新闻，并以 Markdown 日报形式发布到 [GitHub](https://github.com/GuoWenzhu/TechNews)。项目重点关注人工智能、AI Agent、软件工程与技术落地，帮助读者追踪行业动态、理解技术趋势，并发现与现有项目相关的研究和实践机会。

## 关注领域

- **人工智能**：大模型、模型能力、训练方法与研究进展。
- **AI Agent**：智能体框架、工具链、编程助手与应用实践。
- **软件工程**：开发工作流、代码审查、基础设施、安全与部署。
- **技术落地**：产品发布、行业应用、数据分析与工程经验。

## 信息来源与筛选

信息来源以仓库中的 [科技情报来源清单](科技情报来源清单.md) 为依据，分为三个层级：

| 层级 | 来源类型 | 主要用途 |
| --- | --- | --- |
| T1 | 公司一手工程与研究博客 | 获取原始发布、技术细节与实践经验 |
| T2 | 科技媒体与热点聚合平台 | 观察行业热度与讨论焦点 |
| T3 | 论文与模型发布平台 | 跟踪值得关注的前沿研究与模型进展 |

日报主要关注近 48 小时的新内容，按一手性、信息密度以及与工程、Agent 和 AI 落地的相关性筛选，通常保留不超过 10 条重点资讯；有价值的内容不足时，按实际数量收录。

同一内容优先引用一手来源，并按 URL 去重。论文与模型发布侧重高热度或被广泛讨论的成果，每条重点资讯保留原始链接，便于进一步阅读与核查。

## 日报内容

每期日报围绕以下内容展开：

1. **今日要点**：新闻标题、来源层级、一句话核心摘要及原文链接。
2. **项目匹配矩阵**：结合项目主题，标注资讯与项目之间的同频、互补、启发或无关关系。
3. **高价值机会**：提炼值得关注的机会，说明是什么、为什么值得现在关注，以及建议采取的动作。
4. **来源健康与建议**：记录来源可达性与当期产出，提供候选来源及调整建议。
5. **已处理 URL 台账**：保留已整理的链接，支持历史追溯与重复内容识别。

机会分析用于辅助研究和项目判断，具体行动需另行评估与决定。

## GitHub 发布与归档

日报按日期保存为 `digest-YYYY-MM-DD.md`，在 GitHub 仓库中持续发布和归档。读者可直接浏览文件、查阅原始来源，并通过提交历史查看内容变化。

```text
TechNews/
├── README.md                 # 项目说明
├── 科技情报来源清单.md         # 信息来源与收录规则
└── digest-YYYY-MM-DD.md       # 按日期归档的科技情报日报
```

## 阅读方式

- 浏览仓库中的日报文件，按日期了解科技动态。
- 从「今日要点」快速掌握重点，通过原始链接深入阅读。
- 结合「项目匹配矩阵」和「高价值机会」寻找适合自身项目的研究方向。
- 对照历史日报，观察同一主题的演进与持续信号。
