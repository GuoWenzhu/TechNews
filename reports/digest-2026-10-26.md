## 1. Wiz 披露"Gheist"行动：窃取的 GitHub 令牌遭自动化规模滥用，向可达仓库批量植入"倾倒密钥"工作流

- **发布时间**：2026-10-25（Wiz Research 官方博客）
- **来源**：Wiz Research、Hacker News
- **核心内容**：Wiz Research 自 2026-09-15 起跟踪的新攻击行动"Gheist"（得名于其 API 请求用户代理）：自动化利用窃取的 GitHub 令牌，向每个令牌可访问的仓库提交名为 `sync-check` 的 GitHub Actions 工作流；该工作流将仓库密钥（secrets）打印进自身运行日志，随后通过 GitHub API 下载日志并在数秒后删除运行记录。整个行动不依赖 C2 服务器、持续演化。Wiz 已从 850 余个被盗用账号（覆盖个人项目到企业组织私有仓库）恢复出 13,500 余个被植入的分支。GitHub 近期上线的一项安全控制已阻断其在公共仓库的利用，该行动"受到显著扰乱"，但针对私有仓库的风险仍在。
- **背景/影响**：这是一条完整的工业化攻击链——令牌窃取 → 工作流投毒 → 日志回传 → 自我清理，直指 CI/CD 信任模型。对使用 GitHub Actions/GitOps 的团队，细粒度令牌（fine-grained PAT）与最小权限、工作流审批（workflow approval）、运行日志访问控制是直接检查项；Agent 类产品若持有 GitHub 令牌，同样在此攻击面内。
- **原始链接**：
  - https://www.wiz.io/blog/gheist-attempted-scaled-abuse-of-stolen-github-tokens-stumbles
  - https://news.ycombinator.com/item?id=50235010

## 2. 皮肤科医生实测：10 年前的 CNN 诊断皮肤癌准确率 62%，两个前沿大模型仅 42%

- **发布时间**：2026-10-25（Magnus Lynch 医生个人博客）
- **来源**：Lynch Lab（Dr Magnus Lynch）、Hacker News（387 分/184 评）
- **核心内容**：执业皮肤科医生用 200 例活检确诊皮损（来自公开数据集 MILK10k，每例含临床照片与皮肤镜图像，6 类诊断）同题测试 GPT-6 Astra 与 Claude Fable 5.1，并与微调版 Inception v3（Google 2015 年提出的经典 CNN，仅在公开皮肤病学图像上微调约 20 分钟）对比。结果：CNN 答对 125/200（62%），两个前沿大模型分别为 84（42%）与 85（42%）。文中给出典型失败案例：一例耳部侵袭性黑色素瘤（厚 0.8mm），两个大模型均判为无害的脂溢性角化病并建议"无需处理"，CNN 依据皮肤镜图像给出正确诊断。作者指出：专用架构 + 针对性微调 + 结构化图像输入（皮肤镜），在窄任务上仍显著优于通用大模型。
- **背景/影响**：为"大模型替代一切专用模型"的叙事提供了一个严格对照的反例：输入模态（皮肤镜 vs 手机照片）、任务专用微调与判别式架构在医学影像等高风险窄域仍是更优工程选择；对医疗 AI 采购与 Agent 系统中"该路由给专用模型还是通用大模型"的决策有直接参考价值。
- **原始链接**：
  - https://lynchlab.net/llm-skin-cancer
  - https://news.ycombinator.com/item?id=50233779

## 3. 复盘：三个月内 OpenAI 与 Anthropic 旗舰模型降价最多 80%，且质量未缩水

- **发布时间**：2026-10-25（Max Woolf 博客）
- **来源**：Minimaxir（Max Woolf，开发者/数据科学家）、Hacker News
- **核心内容**：作者梳理 6 月以来两大实验室的定价时间线：6-26 OpenAI 发布 GPT-5.6 Sol（$5/$30）与小模型 Luna（$1/$6）；7-30 Luna 直降 80% 至 $0.20/$1.20，作者指出若无此次降价 Luna 将在性价比上输给 DeepSeek V4 Pro；8-10 Anthropic 将 Sonnet 5 的临时促销价转永久；8-21 Sol 降约 20%；9-1 Claude Fable 5.1 把缓存读取成本砍 75%（Agent 编码场景缓存读取占 token 总支出 96%–99%，等效总成本降 70%–75%）；9-22 GPT-6 Sol 以 $2/$10 上市、同日 Anthropic Opus 5.5 总成本降 40%–60%；9-29 GPT-6.1 Sol 缓存价格再砍半。结论：自 6 月至今主流模型"使用成本崩塌式下降"，且第三方评测显示没有以牺牲质量为代价；订阅制 Agent 工具（Claude Code、Codex 等）同步受益。
- **背景/影响**：降价主因是开源/低价模型竞争（如 DeepSeek）与推理效率（尤其缓存）优化，而非需求疲软；对企业 AI 预算与 Agent 产品毛利测算，这是成本曲线实质性下移的直接证据——按 6 月价格做的成本模型需要重新校准。

  - https://minimaxir.com/2026/10/cheap-llms/

- **来源**：DreamHost 官方状态页、Hacker News（103 分/37 评）
- **核心内容**：老牌主机商 DreamHost（持有其账户即网站/FTP/邮箱所有者）爆发影响文件管理器与网页邮箱的服务中断，并强制受影响用户重置密码：10-24 18:09 PDT 起分批向受影响账户所有者发送重置指引邮件，10-25 11:43 PDT 官方称"大部分邮件已发出"，用户亦可不经邮件直接在控制面板重置邮箱与 SFTP 密码；官方同时提醒"DreamHost 永远不会发邮件向你索要密码"。截至最新更新，文件管理器 files.dreamhost.com 仍不可用。官方未披露事件根因（是否数据泄露）。

## 6. "上下文工程现状"：AGNTCon 演讲全文——核心是判断"何时确定性、何时概率性"

- **发布时间**：2026-10-24（Drew Breunig 博客）
- **来源**：dbreunig.com（Drew Breunig，《The Context Engineering Handbook》作者，O'Reilly）、Hacker News
- **核心内容**：作者发布其在 AGNTCon 的演讲"Context Fails & Fixes"全文（幻灯片 + 编辑整理的讲稿），作为一份"上下文工程现状"综述：上下文工程如何出现、当前走到哪里、向何处去。核心论点：这项工作的本质是知道何时该用确定性手段、何时接受概率性手段；模型厂商每次追逐新能力，都会给用户与 harness 构建者制造新的上下文挑战。作者还回顾了 O'Reilly 编辑 2025 年 6 月的经典疑问"这本书会不会几周就过时"，以及他基于"给智能体清晰、一致、低噪声的指令永远绕不开"作出的判断。
- **背景/影响**：上下文工程已从零散技巧收敛为可教学的工程学科（O'Reilly 教材 + 行业会议专题）；对 Agent/工作流系统的提示与上下文设计（确定性护栏 vs 概率性生成边界划分）是一份成体系的一线实践综述。
