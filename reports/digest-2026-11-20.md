## 2. Anthropic 披露 Claude 以自主 agent 研究小组解决两个黑洞物理开放问题，结果经 Lean 形式化验证

- **发布时间**：研究页面 2026-11-18 21:42 UTC 更新（页面未标注原发日期，以此与 HN 提交时间为准）；Hacker News 11-19 17:30 UTC 起 347 分
- **来源**：Anthropic Research（一手）；hexagonmath.org 预印本 2611.00174 / 2611.00175（一手产物）；Hacker News（讨论）
- **核心内容**：Anthropic 研究员 Hongbin Chen 于 8 月让 Claude 列出 22 个黑洞物理/自举（bootstrap）方向的理论物理开放问题，并为每个问题部署独立后台 agent（可互相查看进展、协作），运行约 6 周后解决其中两个：(a) 完成 2003 年由 Aharony 等人设置、20 余年无人完成的 N=4 超对称杨-米尔斯理论弱耦合 Hawking-Page 相变计算（数千项费曼图求和且需处理无穷大），证明该相变是"陡峭"的一级相变，与 1983 年 Hawking-Page 在强耦合端的结论一致；(b) 借用其他领域的谱曲线（spectral curve）数学工具，证明 3D 量子引力模块化 bootstrap 对最轻黑洞质量上界 M₁ ≤ c/9.1266…（精确公式），并证明该界不可再改进，是 15 年来该技术首次被压到精确最优。两个结果于 9 月经 Lean 证明检查器形式化验证；Claude 自主起草论文，物理学家逐项核查主要结果；期间一位独立物理学家用不同方法得到相同 Hawking-Page 结论，互为校验；方法链中还复现了 OpenAI 模型近期证明的高维球堆积结果。
- **背景/影响**：两个结果均不直接描述现实宇宙、暂无实用应用，但这是"自主长周期科研 agent"迄今最强的公开案例之一：多 agent 分工、跨文献识别模式、形式化验证闭环与人类抽查结合。对科研自动化与 agent 工程都是重要信号。

## 4. OpenAI 公布全自主"Performance Factory"：Codex agent 工作流 3 个月自动调查 1,700+ 次性能回归、定位 600+ 次根因

- **发布时间**：2026-11-19 08:00 UTC（官方博客 RSS）
- **来源**：OpenAI 官方博客（一手）
- **核心内容**：OpenAI 披露其内部"Performance Factory"——云端运行的自主 agent 工作流系统，用于跟上 agent 化开发带来的性能工程压力。首个 Regression Workflow 自动完成"告警触发→根因调查→提出修复 PR→工程师评审合并→部署后验证恢复"全链路：上线 3 个多月跟踪 1,700+ 次调查、定位 600+ 次根因（约每天 17 次自动调查）。系统由四部分组成：带可配置工作流的任务服务、给就绪任务派发 agent 的调度循环、在内网环境运行 Codex 的云端 API、以及在评审/部署等事件发生时唤醒 agent 的订阅机制。关键工程实践：沉淀 perf-forensics 共享调查技能；为每个诊断与修复引入"对抗性评审"会话主动推翻结论（人工抽检 100 个根因建议，70% 准确）；任务状态与发现存于任务本身而非单个 agent 上下文；每日运行自检 agent 发现工具故障并用系统自身修复（自修复闭环）；对调查质量用历史事故回放做 evals 回测。下一步探索 agent 自主合并低风险修复与主动发现告警之外的性能优化。
- **背景/影响**：这是目前披露最完整的"agent 软件工厂"生产级实践：任务状态机 + 对抗评审 + 回放式评测 + 自我修复，几乎是一份可复用的生产 agent 运维蓝图；"工程师角色从执行转向评审与定义工作流"的组织含义，与本周 Nadella 关于 11 人 Cowork 团队"造造产品的工厂而非产品"的表态相互印证。

- **背景/影响**：针对 Apple-加密之争两年来的"绝对保密"体制首次被司法打破，全球端到端加密政策博弈与"政府密令改动消费设备安全"的公共监督获得先例；TCN 体制可适用于任何通信服务商，安全与合规团队值得持续跟踪。

## 7. Ruby2Shell（CVE-2026-132825）：单字节堆溢出可未认证打到默认配置 Rails，GitLab/GitHub Enterprise 尚无修复版

- **发布时间**：2026-11-18（ruby-lang.org 官方安全公告）；Veria Labs 披露页更新于 2026-11-19 23:59 UTC；Hacker News 11-19 05:09 UTC 起 378 分
- **来源**：Veria Labs 技术披露（一手）；ruby-lang.org 官方公告、ruby/ruby 修复提交（一手）；Hacker News（讨论）
- **核心内容**：Ruby 单字节编码字符串大小写转换循环中，大写德语 ß 需写出两字节（SS）但边界检查只预留一字节：输入含 21 个 ß 即对输出缓冲区一字节堆溢出（写入 S/s 后越界读写各一字节）。缺陷自 Ruby 2.4.0 起存在于多个 ISO-8859/Windows-125x 编码路径，经 upcase、swapcase、downcase(:fold)、casecmp? 可达；UTF-8 走不同代码路径不受影响。默认配置下 Rails 与 classic Sinatra 可被未认证触达。修复版本：4.0.10 / 3.4.13 / 3.3.14（官方公告同批修复另两个 Regexp/大小写转换缺陷）。自托管产品：GitLab ≤19.6.0、GitHub Enterprise Server ≤3.22.5、Chatwoot ≤4.20.0 截至披露时所有现行版本均未修复（依赖厂商发版）；Mastodon、OpenProject、Discourse 已发布补丁版本。Veria Labs 预告最早 11-25 公开在默认 Rails 上远程代码执行的 PoC。官方公告同时致谢 Stephan Lipp（Ada Logics）与 Anthropic 报告底层缺陷，Moritz Sanft 与 OpenAI 协作发现相关漏洞。
- **背景/影响**：继 NGINX 双 RCE（11-18）与 Java4Shell 之后，互联网基础软件高危漏洞潮延续；"运行时 11 年老缺陷 + 默认框架可未认证触达"的组合意味着大量自托管 Ruby 服务需立即按官方公告升级；RCE PoC 将至，修复窗口紧迫。

- **背景/影响**：与 OpenAI Performance Factory（任务状态机工作流）、GitHub Agent Host Protocol（跨设备会话延续）同向，agent 编排基础设施正在分层成形：协议层、协调层、工作流层各自出现专用原语；"agent 间共享状态"从脚本 hack 走向托管服务，是团队级 agent 落地的关键缺口之一。

- **核心内容**：The Information 报道，Meta 计划将其"电子宠物"式随身 AI 设备 Muse Charm 定价约 300 美元；该设备在今年 Connect 大会上预展，可放入口袋或挂颈佩戴，用户可与 Meta 的 agent 助手 Muse 语音交互、下达指令。TechCrunch 向 Meta 求证，发言人未否认，仅回应"我们对 AI 设备的关注深感荣幸（charmed），很快会分享更多"。Muse 目前是带拟人化头像的 agent 应用，Charm 是其硬件化延伸。可比价位：Friend AI 佩戴设备 250 美元、Amazon Bee Frontier 75 美元（含 99 美元/年订阅）。
- **背景/影响**：消费级 AI 硬件此前屡屡受挫（如 Humane Ai Pin 收场），Meta 以"成熟软件 agent + 随身硬件载体"的组合再度尝试，300 美元定价显示其对 Muse 应用粘性的信心；这也是继 Ray-Ban 眼镜之后 Meta AI 硬件组合的第二条产品线，其成色将检验"agent 随身化"的真实需求。
